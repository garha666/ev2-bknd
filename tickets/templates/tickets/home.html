Plataforma de Venta de Entradas

Backend desarrollado con Django REST Framework y PostgreSQL para la evaluación EVA-2. Gestión de eventos, sectores, carro persistente, checkout transaccional y emisión de entradas con UUID.

Recursos de la API

  • Documentación Swagger / OpenAPI
  • Estado del sistema y datos del alumno
  • Catálogo de eventos (público)
  • Autenticación JWT

Endpoints principales

GET /api/eventos/ · GET /api/eventos/{id}/sectores/

GET/POST /api/carro-tickets/ · DELETE /api/carro-tickets/{id}/

POST /api/compras/pagar/ · PATCH /api/compras/{id}/estado/

GET /api/mis-entradas/
